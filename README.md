# Adedipe Oluwatimilehin — Engineering Portfolio

A responsive, dark-themed personal portfolio website built with HTML, CSS, and JavaScript.

## Files
- `index.html` — portfolio content
- `styles.css` — layout and responsive styling
- `script.js` — mobile navigation and current year
- `assets/Adedipe_Oluwatimilehin_CV.pdf` — downloadable CV

## Preview locally
Open `index.html` in a web browser.

## Publish for free
You can publish this static site using GitHub Pages:
1. Sign in or create an account at https://github.com/
2. Create a new public repository (for example, `adedipe-portfolio`).
3. Upload the files and folders in this package, keeping the `assets` folder.
4. In the repository, open Settings → Pages.
5. Choose deployment from the `main` branch and the root folder, then save.
6. GitHub will provide a public website address after deployment completes.

Before publishing, review the personal contact details and downloadable CV. Consider whether you want your phone number publicly visible.
